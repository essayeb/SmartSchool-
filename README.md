# SmartSchool, le portail de gestion scolaire

## Lancer le projet
1. Téléchargez et extrayez `SmartSchool.zip`.
2. Ouvrez le dossier `smart-school`.
3. Double-cliquez sur `index.html` ou ouvrez-le avec Live Server dans VS Code.

Aucune installation, aucun serveur et aucune base de données ne sont nécessaires pour cette démonstration.

## Fonctionnalités front-end
- Tableau de bord avec indicateurs, graphiques CSS et activités récentes.
- Navigation entre les espaces Élèves, Enseignants, Présences, Notes, Emploi du temps, Rapports, Messages et Paramètres.
- Recherche instantanée dans le tableau des élèves.
- Recherche globale et raccourci Ctrl/Cmd + K.
- Interface responsive pour ordinateur, tablette et mobile.
- Fenêtre d'information pour les actions nécessitant un backend.

## Important — état du projet
SmartSchool est une **maquette front-end de démonstration**. Les données affichées sont fictives et servent uniquement à présenter l'interface. Les actions nécessitant un traitement serveur (création, modification, suppression, authentification, sauvegarde, export réel, envoi de messages, etc.) affichent un message indiquant que le site n'est pas encore publié et que les travaux sont en cours.

## Technologies
- HTML5
- CSS3 (Grid, Flexbox, responsive design)
- JavaScript (DOM, événements, recherche et navigation)

## Évolutions possibles
